# ARK 客服知识库

支持分类侧边栏、模糊搜索、繁简中文、标签筛选的客服快速搜索工具。

## 功能特性

- 📂 **分类侧边栏** - 8 大分类（活动公告 / 提案政策 / 工作室事务 / 常用话术 / 产品操作 / 常见 FAQ / 地址合约）
- 🔍 **模糊搜索** - 基于 Fuse.js 模糊匹配
- 🌐 **繁简兼容** - 自动识别繁体/简体中文
- 🏷️ **标签筛选** - 输入 #标签 快速筛选
- 🔗 **链接直搜** - 直接输入链接查找对应记录
- ⭐ **收藏功能** - 常用话术钉到顶部（localStorage 存储）
- 📋 **一键复制** - 快速复制答案到剪贴板
- 🌙 **深色主题** - 科技感深色界面
- 📱 **移动端优化** - 响应式设计，支持 PWA
- 💾 **离线支持** - Service Worker + 数据缓存

## 数据格式

每条记录使用以下格式（`---` 分隔）：

```
[问题/关键词]: 关键词1 关键词2 关键词3
[标签]: #分类 #二级标签
[图片]: images/分类/2026-07-02-描述.png    ← 可选
[答案]: 答案正文
[链接]: 
                    ← 可选
---
```

`[图片]` 字段是可选的。如果某条记录有配图，存到 `data/images/对应分类/` 目录，命名 `YYYY-MM-DD-简短描述.png`。

## 部署到 GitHub Pages

1. 将本文件夹内容推送到 GitHub 仓库
2. 进入仓库 **Settings** → **Pages**
3. **Source** 选择 **main** 分支和 **/ (root)**
4. 保存后等待 1-2 分钟访问

## 本地测试

```bash
cd g:\kefuhuifu
python -m http.server 8080
# 访问 http://localhost:8080
```

## 密码保护

由于 GitHub Pages 是静态托管，**无法做真正的服务端认证**。当前使用前端 JS 密码保护：

### 改密码

打开 `index.html`，找到这行（大约在第 360 行）：

```js
const KB_PASSWORD = 'ark2026';
```

把 `'ark2026'` 改成你要的密码（**用强密码**），保存，commit，push。

### 安全等级说明

| 场景 | 是否能挡住 |
|---|---|
| 防搜索引擎 / 普通访客 | ✅ |
| 防路人随便看 | ✅ |
| 防有人看源码找密码 | ❌（密码在 JS 里能看到） |

**适合**：4-5 人的客服团队内部使用。
**不适合**：高度敏感数据 / 公开服务。

如果需要更强的保护，迁移到 Cloudflare Pages + Pages Functions（服务端校验）。

### 退出登录

侧边栏底部有 **"⏻ 退出登录"** 按钮，会清除 localStorage 重新要求密码。

### 换设备 / 换浏览器

新设备 / 浏览器需要重新输密码（localStorage 不跨设备）。

## 技术栈

- **模糊搜索**: Fuse.js
- **中文分词**: segmentit
- **繁简转换**: OpenCC-JS
- **离线缓存**: Service Worker + Cache API
- **PWA**: manifest.json + Service Worker
- **存储**: localStorage（收藏、登录状态）
