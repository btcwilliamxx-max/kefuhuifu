[问题/关键词]: 赎回 本金 扣除 贡献值 负数 机制 解析
[标签]: #ARK #政策
[子条目 ID]: gxz_redeem_parent
[子条目]: gxz_sub1, gxz_sub2, gxz_sub3
[答案]: 关于“赎回本金会扣贡献值”的机制解析

很多伙伴最近对“为什么赎回会扣贡献值、为什么会出现负数”存在疑问，下面统一做一个通俗解释。

1、哪些质押不会扣贡献值？
如果是贡献值新机制上线之后产生的质押，本身就不会再产生贡献值，因此：到期不会扣贡献值，提前赎回也不会扣贡献值，也就是说：新机制后的配套，与贡献值已经脱钩。

2、哪些会扣贡献值？
在贡献值新机制上线之前：单币质押，债券配套这些都会产生贡献值。
因此：只要是“老机制时期”的配套，无论到期还是赎回，系统都会同步扣除当初对应产生的（5倍）贡献值。

3、为什么贡献值会变成负数？
这是大家最容易困惑的地方，举个例子：你账户目前只剩200贡献值，但你现在有一笔100美金的老配套到期/赎回；按照老机制：1美金=5倍贡献值，那么系统需要扣除：100×5=500贡献值；你账户里只有200贡献值，因此：200-500=-300，于是就出现贡献值负数。
本质上是：账户当前剩余贡献值，不足以抵扣历史应扣回的贡献值。

4、为什么赎回老配套，会把新产生的贡献值也扣掉？
因为系统扣除贡献值时：不会区分“旧贡献值”还是“新贡献值”，只认你账户当前总贡献值；所以：你之前老配套产生的贡献值已经被动态消耗掉了。当旧本金赎回时：系统需要扣回历史对应贡献值，当账户原来的贡献值不够，就会继续扣你后面新增的贡献值。
因此有人会感觉：“为什么我新做的贡献值也被扣了？”这是因为之前的贡献值已经提前被动态收益消耗完了。

5、贡献值出现负数怎么办？
解决方法很简单：赎回或到期的本金重新参与质押即可恢复。

6、这样算下来是不是不划算？
很多人只看到“扣贡献值”，却忽略了：贡献值本身已经帮你放大过收益。因为旧机制里：贡献值对应的是动态收益权限，也就是说：如果你的贡献值已经被消耗完，你已经提前享受了5倍动态收益。
另外本金在这个过程中还会产生：静态利息收益，利息领取是不会扣贡献值，在长周期下，利息收益还非常可观。
所以不能单独只看：“扣了多少贡献值”，而是应该看：整个周期你实际拿到了多少收益。

質押產生的靜態收益，不會扣除貢獻值；只有動態獎勵，才會扣除對應貢獻值。

[问题/关键词]: 平级 奖励 产生 条件 比例 同线 S4
[标签]: #ARK #政策
[答案]: 1️⃣ 平級產生條件
當同線成員之間出現相同級別（如皆為 S4）時，往上最近的兩個同級點位可獲得「平級獎勵」資格。

• 例：若 D → C → B → A 均為 S4，
 則 C 與 B 為可領取平級獎勵的對象。
 A 因為已超過兩層，不再享有平級獎勵資格。

⸻

2️⃣ 平級獎勵比例
平級獎勵按「最近一個平級點位」的動態計算，
比例為該級別獎勵的 10%。
（即距離越近、獎勵越優先）

⸻

💡如圖示例
• D → C（S4）→ B（S4）→ A（S4）
 → C、B 可領；A 不可領。
 → 平級獎勵分配按最近平級（C 為第一層、B 為第二層）依序計算。

[问题/关键词]: MBR 上涨 卖币 原因 抑制 套利 平滑 价格 节奏
[标签]: #ARK #政策
[答案]: 二、为什么 MBR 有时候会在上涨过程中卖币？
MBR 的设计初衷之一，就是对 RBS 机制进行补充，提升整个系统在市场运行中的灵活性。
由于我们拥有较大的流动性底池，因此市场上存在不少专门关注项目价格波动的套利机器人和超短线交易者。这些资金往往会利用短时间内的价格波动进行高频套利，从而加剧市场波动。

当价格出现过快上涨时，MBR 可能会根据策略进行适度卖出，主要有两个目的：
1  抑制短期套利行为
避免部分套利资金利用价格快速拉升获取过高收益，降低对系统长期稳定性的影响。
2  平滑价格上涨节奏
防止价格在短时间内脱离正常增长区间，减少剧烈波动带来的风险，让市场运行更加健康和可持续。

需要特别说明的是：
MBR 的目标并不是阻止价格上涨；
MBR 不会主动压制市场趋势；
MBR 只是让上涨过程更加平稳，而不是更加剧烈。
这一逻辑与 RBS 的设计理念是一致的，即通过机制调节来降低市场波动，促进生态长期健康发展。
至于有些成员会发现，某一天价格上涨后，第二天没有继续快速上涨，甚至出现横盘或回调，这本质上更多是由市场买盘强弱决定的。换句话说，后续涨幅是否能够延续，取决于市场新增资金和真实购买需求，而不是 MBR 在控制价格走势。

因此，大家应该把 MBR 理解为一个维护市场稳定运行的辅助机制，而不是决定价格涨跌的主导力量。它所做的是优化市场运行节奏，而非改变市场最终方向。

🗳 ARK #018 号提案：系数稳定性优化 —— 保系数改按币量判定
━━━━━━━━━━
📘 提案简介(Summary)
针对近期币价波动对系数稳定性的影响，本提案对系数考核机制进行结构性优化。
* 晋升考核 → 规则维持不变
* 联盟激励 → 规则维持不变
* 降级考核 → 按币量（币本位）判定，锁定晋升当下的次要系数的币量
📌核心方向：降系数判定改按币量执行，让伙伴们的系数不再受币价短期波动影响。
━━━━━━━━━━
🎯 提案目的(Purpose)
1️⃣ 稳定系数权益 —— 让系数不再受币价波动影响，权益长期稳固；
2️⃣ 激励长期持有 —— 让「拿得住币」成为核心能力；
3️⃣ 穿越周期 —— 减少短期市场情绪对社区结构的干扰。
━━━━━━━━━━
⚙️ 执行内容(Implementation Details)
一、晋升规则维持不变：达到对应系数的 U 价值（本金 + 利息合并计算）门槛即可晋升
二、降级规则改变 —— 币本位（币量）
🔹 锁定机制： 当伙伴晋升到某一系数的晋升当下，合约自动锁定当下次要系数的币量作为该系数的保系数基准。
🔹 判定维度： 系数降级考核按币量（本金 + 利息合并计算），不受币价波动影响。
🔹 系数规则：
✅ 币量 ≥ 锁定值 → 系数永久有效
❌ 币量 < 锁定值 → 相应下调系数
三、联盟激励 —— 本金币量
🔹 联盟激励统一按本金币量计算，规则维持不变。
━━━━━━━━━━
四、配套调整：活期质押
为实现「按币量自动统计保系数」，需对活期质押做同步调整：
* ✅ 目前已开启的活期质押 → 不受影响，可继续质押持有
* ❌ 取出后 → 不可再次存入（即不再开放新的活期质押入口）
━━━━━━━━━━

🎯 提案目的(Purpose)
1️⃣ 构建永久权益体系 —— 让长期持有者获得清晰的股东身份与生态权益凭证；
2️⃣ 强化通缩机制 —— 通过本金销毁，持续降低流通供应；
3️⃣ 承载生态未来收入 —— 为阿奇 AI、ARKIE 代币等未来商业化收益提供分配载体；
4️⃣ 形成长期正向循环 —— 销毁 → 权重 → 权益 → 更多销毁，代币持续通缩。
━━━━━━━━━━
⚙️ 执行内容(Implementation Details)
一、核心定位
阿奇 NFT（永久配套）= 永久股东身份 + 生态权益凭证
━━━━━━━━━━
二、获取方式
A. 现有配套升级
* 现有配套可直接升级为阿奇 NFT（永久配套）
* 本金部分立即销毁 → 按 1 ARK = 1 NFT 权重 转化

B. 新购买
🔹 方式 1：单笔永久质押
* 用户以 USDT 购买
* USDT 进入底池，按当前币价购入 ARK 并立即销毁
* 按 1 ARK = 1 NFT 权重 换算
🔹 方式 2：永久债券
* 用户以 USDT 购买
* USDT 进入底池，按当前币价购入 ARK 并立即销毁
* 销毁的 ARK 数量按折扣系数放大换算为 NFT 权重（获得更高权重）
* 同步触发一定比例铸币，注入联盟激励池

用户支付 1,000 USDT，币价 5U → 底池购得 200 ARK → 立即销毁 200 ARK

把公告内容和大纲组合起来，线上会议讲解内容

一、核心定位
阿奇 NFT 的定位是：永久股东身份 + 生态权益凭证。

两个关键词：

永久：一次获得，持续享有权益

股东：你不是普通用户，你是生态的长期股东

ARK 生态未来所有商业化收入 —— 包括阿奇 AI、ARKIE 代币等，都会通过这个 NFT 进行分配。

二、获取方式
有三种途径：

A. 现有配套升级
已有的配套可以直接升级为阿奇 NFT。升级后，本金部分立即销毁，按 1 ARK = 1 NFT 权重 换算。

B. 单笔永久质押（新购）
用户用 USDT 购买 → USDT 进入底池 → 按市价购入 ARK → 立即销毁 → 按 1:1 换算为 NFT 权重。

C. 永久债券（新购）
这是三种方式里权重效率最高的一种。

同样是 USDT → 买 ARK → 销毁，但销毁的 ARK 数量会按折扣系数放大换算，获得更高权重。

举例：用户支付 1,000 USDT，币价 5U，底池购得 200 ARK 并销毁。如果债券是 97 折，权重换算为 200 ÷ 0.97 ≈ 206 NFT 权重——同样的销毁量，拿到更多权重。

同时，永久债券会同步触发一定比例的铸币，注入联盟激励池。

三、NFT 核心特性
三个特性：

① 不可转让
NFT 与地址永久绑定，不能交易、不能出售、不能转移。这确保只有真正的长期持有者才能享受权益。

② 产生联盟激励业绩
1 NFT 权重 = 1 ARK 的业绩计算逻辑，和原有 ARK 完全一致。

③ 收益可无损复投
这是权重增长的核心路径。

举例：永久配套本金 1,000 NFT 权重，产生了 300 ARK 的收益，一键复投后，NFT 权重就变为 1,300。收益变权重，权重产生更多收益，持续复利增长。

四、权益体系
这是大家最关心的部分。

权益 1：Rebase 收益自动复利
高于 720 天配套的 Rebase 收益，系统自动执行复利，持续提升 NFT 权重，无需手动操作。

权益 2：ARKIE 代币空投
ARK 每笔交易有 2.5% 手续费，其中 0.5% 用于回购 ARKIE 代币，按阿奇 NFT 权重进行空投。权重越高，空投越多。

权益 3：ARKIE 代币手续费分红
ARKIE 代币每笔交易有 2.5% 手续费，其中 1.5% 作为权益，分配给符合资格的阿奇 NFT 持有者。

关键资格条件：持有者必须从未卖出过 ARK。 一旦发生卖币行为，即失去该项权益资格。这个机制就是要激励真正的长期持有者。

权益 4：阿奇 AI 盈利权益
未来阿奇 AI 正式对外商业运营后，AI 的营收将按 NFT 权重进行分配。具体比例和规则届时另行公布。

五、机制解决的核心问题
这个提案解决了两个关键问题：

第一，算法非稳定币的持续增发问题。 通过本金销毁机制，构建了一个长期通缩通道。销毁的 ARK 越多，流通越少。

第二，阿奇 AI 未来商业盈利的分配问题。 用 NFT 权重作为清晰、透明、不可篡改的分配依据，解决了"赚了钱怎么分"的问题。

六、长期逻辑闭环
最后，整个机制形成了一个正向循环：

未来生态产生的各类收入、空投、权益 → 持续回流至阿奇 NFT 持有者 → 持有者以股东心态长期持有 → 持续将收益燃烧复投 → NFT 权重不断提升 → 获得更多生态权益 → 代币持续通缩 → 生态长期健康发展。

销毁 → 权重 → 权益 → 更多销毁，代币持续通缩，形成长期正向闭环。
